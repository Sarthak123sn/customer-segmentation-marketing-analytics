# Customer Segmentation and Marketing Analytics Using Unsupervised Machine Learning

A college ML mini project using K-Means clustering to discover customer groups from the Mall Customers dataset.

## Features
- Exploratory data analysis and data-quality checks
- Feature scaling before distance-based clustering
- Elbow method and silhouette score to guide selection of cluster count
- Cluster visualizations and segment profiles
- Streamlit dashboard with interactive feature selection and marketing insights
- Optional CSV upload for compatible customer datasets

## Dataset
The default dataset is the commonly used Mall Customers dataset (200 rows; columns usually include CustomerID, Gender/Genre, Age, Annual Income (k$), and Spending Score (1-100)).

Dataset source page: https://github.com/hannazan/mall-customer-segmentation/blob/main/data/Mall_Customers.csv

The notebook and app attempt to load the raw CSV from GitHub. If that URL is unavailable, download `Mall_Customers.csv` from the source page and upload it when prompted or place it beside `app.py` / the notebook.

**Dataset limitation:** this educational dataset contains income and spending score, not detailed transaction history. Marketing recommendations are illustrative hypotheses based on cluster profiles, not proof that a campaign will work.

## Run in Google Colab
1. Upload `Customer_Segmentation_and_Marketing_Analytics.ipynb` to Google Colab.
2. Run the cells from top to bottom.
3. If the remote CSV cannot be loaded, download the CSV from the dataset source and upload it when prompted.
4. Review the computed cluster counts, silhouette score, and plots before writing final results in your report.

## Run Streamlit locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
Then open the local URL shown in the terminal.

## Deploy on Streamlit Community Cloud
1. Push the files in this project folder to a GitHub repository.
2. Open https://share.streamlit.io/ and connect the repository.
3. Select `app.py` as the main file.
4. Deploy and test the public app URL.

## Project structure
- `app.py` — Streamlit dashboard
- `Customer_Segmentation_and_Marketing_Analytics.ipynb` — full ML workflow
- `requirements.txt` — Python dependencies
- `README.md` — setup and project documentation

## Methods
- K-Means clustering
- StandardScaler
- Elbow method (inertia)
- Silhouette score
- PCA-based 2D view when more than two features are selected

## Important
Do not report a made-up accuracy score. Clustering is unsupervised, so classification accuracy is not an appropriate metric without ground-truth segment labels. Report the silhouette score and cluster profiles generated by running the notebook.
